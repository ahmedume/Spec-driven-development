# Inspiration Sources Reference

Read this during Phase 0 before starting any design.
This file tells you WHERE to look and HOW to use references without copying.

---

## Primary Sources (always check these first)

### 1. Awwwards (awwwards.com)
- **What's there:** The highest-caliber web design globally. Site of the Day winners.
- **Best for:** Understanding current state-of-the-art, motion direction, layout ambition
- **How to search:** `site:awwwards.com [industry] 2024` or use their categories
- **What to extract:** Layout structure, color philosophy, motion character — never visual details

### 2. Dribbble (dribbble.com)
- **What's there:** UI design shots, often more polished than real — use for visual inspiration
- **Best for:** Color palettes, typography combinations, component design ideas
- **How to search:** `site:dribbble.com [industry] website 2024`
- **What to extract:** Color mood, type hierarchy, one layout idea

### 3. Behance (behance.net)
- **What's there:** Full case studies, brand identity + web, print + digital
- **Best for:** Understanding the *system* behind a design, brand application
- **How to search:** `site:behance.net website redesign [industry]`
- **What to extract:** Brand system, naming conventions, content strategy

### 4. Land-book (land-book.com) / Lapa Ninja (lapa.ninja)
- **What's there:** Landing page galleries, organized by industry
- **Best for:** Quick reference for landing page conventions in a specific niche
- **What to extract:** What sections exist, what CTAs are used, what tone they adopt

### 5. Godly.website / Dark Mode Design
- **What's there:** Curated sites with dark/moody aesthetics
- **Best for:** Dark-themed products, developer tools, creative agencies

## Adjacent-Industry Inspiration (the secret weapon)

The best designs borrow ideas from adjacent worlds. If you're designing for:

| Client Type | Look Here Instead |
|-------------|-------------------|
| SaaS / Developer tool | Swiss modernist print design, Bloomberg Terminal UI |
| Fintech / Banking | Luxury watch brand sites (Patek Philippe, IWC) |
| AI / ML product | Scientific journal layouts, CERN visual identity |
| Healthcare | Nordic government sites (GOV.UK, danish.design) |
| E-commerce | High-fashion editorial (Bottega Veneta, Loro Piana) |
| Agency / Studio | Record label sites (4AD, Sub Pop, XL Recordings) |
| Food / Restaurant | Architecture firm sites (Kengo Kuma, BIG) |
| Crypto / Web3 | Industrial design brands (Braun archive, Dieter Rams) |
| Gaming | Film production company sites (A24, NEON) |

## How to Use a Reference Without Copying

### The Three-Layer Extraction Method

**Layer 1: Structure** (safe to adapt)
- How many columns? What's the reading direction?
- Where does the eye travel first, second, third?
- What's the proportion of white space to content?

**Layer 2: Principle** (adapt the idea, not the execution)
- "This site makes the headline do all the work — I'll do that, but with different type"
- "This uses color inversion on scroll — I'll do that, but triggered by sections not pixels"
- "This has a very quiet nav that disappears — I'll do that, but mine slides in on scroll-up"

**Layer 3: Mood** (translate, don't copy)
- "This feels precise and deliberate" → your version uses tight grid + monospace labels
- "This feels energetic and kinetic" → your version uses oversized type + fast transitions
- "This feels trustworthy and calm" → your version uses generous whitespace + muted palette

**Never copy:** Color codes, font choices, specific component shapes, layout proportions exactly, copy/text.

## Search Queries That Actually Work

```
# For a SaaS landing page
site:dribbble.com saas landing page minimal 2024
site:awwwards.com B2B software site of the day

# For a portfolio
site:awwwards.com portfolio experimental typography
site:behance.net creative portfolio website 2024

# For a restaurant / food brand
site:awwwards.com restaurant website SOTD
site:dribbble.com food brand website concept 2024

# For a dark/moody aesthetic
site:godly.website dark mode SaaS
site:dribbble.com dark UI dashboard minimal 2024

# For editorial / content sites
site:awwwards.com editorial magazine website
site:behance.net digital magazine redesign

# For e-commerce
site:awwwards.com e-commerce site of the day
site:behance.net fashion e-commerce concept
```

## Quickly Judging if a Reference is Worth Using

Ask three questions:
1. Would a non-designer notice this is beautiful? (If yes, it's a good ref)
2. Could I describe the layout in 10 words? (If yes, I can adapt the structure)
3. Is there ONE thing here I've never seen done this way? (If yes, extract that idea)

If the answer to all three is no — find a different reference.

## What NOT to Do With References

- ❌ Replicate the color scheme directly
- ❌ Use the same fonts
- ❌ Reproduce the grid/proportion exactly
- ❌ Copy the CTA language or section names
- ❌ Use the same image treatment (cropping style, filter, ratio)
- ❌ Mention the reference to the client (you internalized it, you didn't trace it)
