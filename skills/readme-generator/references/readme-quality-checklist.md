# README Quality Checklist

Before delivering a README, verify every item:

## Completeness
- [ ] Title with badge row (version, license, build status)
- [ ] 2-3 sentence description of what and why
- [ ] Table of Contents
- [ ] Features table
- [ ] Tech stack table
- [ ] Requirements with minimum versions
- [ ] Installation steps (clone, install, configure, run)
- [ ] Configuration reference (.env variables)
- [ ] Usage examples with code snippets
- [ ] API documentation (if applicable)
- [ ] Project structure tree
- [ ] Database schema (if applicable)
- [ ] Testing instructions
- [ ] Deployment guide
- [ ] Contributing guidelines
- [ ] License
- [ ] TLDR summary at the very bottom

## Media
- [ ] Asked user about screenshots/video/both/neither
- [ ] Included media if user requested it

## Correctness
- [ ] All config files read (package.json, pyproject.toml, etc.)
- [ ] Tech versions match actual project
- [ ] Commands actually work (npm test, npm run build, etc.)
- [ ] File paths referenced are correct
- [ ] Badge URLs are valid
